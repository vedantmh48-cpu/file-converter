# File Converter

A free, fast, and secure online file conversion tool built with React. Convert images, documents, and more directly in your browser — no uploads to servers, everything stays on your device.

## Features

- **Image Conversion** - Convert between PNG, JPG, WEBP, GIF, BMP, TIFF, and SVG
- **Document Conversion** - Convert between PDF, DOCX, TXT, and HTML
- **Spreadsheet Conversion** - Convert between XLSX, CSV, and JSON
- **100% Client-Side** - All conversions happen in your browser. Your files never leave your device.
- **No File Size Limits** - Convert files of any size
- **Free & Open Source** - No hidden costs, no sign-ups required

## Live Demo

Check out the live version: [https://vedantmh48-cpu.github.io/file-converter](https://vedantmh48-cpu.github.io/file-converter)

## Tech Stack

- React 19
- Tailwind CSS
- Framer Motion
- PDF-lib, jsPDF, Mammoth.js
- SheetJS (xlsx)
- JSZip
